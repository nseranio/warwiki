# Evaluation & Workup

The Evaluation section covers history, physical examination, imaging, laboratory studies and ancillary testing in functional and reconstructive urology and urogynecology.

Tests are chosen to answer a clinical question and are interpreted with symptoms, examination, anatomy and patient goals. The pages below explain indications, reference values and limitations.
