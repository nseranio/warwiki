The Evaluation section covers **history, physical examination, imaging, laboratory studies and ancillary testing** in functional and reconstructive urology and urogynecology. It emphasizes validated phenotyping tools, the imaging studies that change reconstructive decisions (RUG, VCUG, MAG3, dynamic pelvic-floor MRI, contrast-enhanced voiding urosonography) and the ancillary tests that inform treatment (urodynamics, cystoscopy, anorectal manometry).

Tests are chosen to answer a clinical question and are interpreted with symptoms, examination, anatomy and patient goals. Stricture length, split renal function and urodynamic measurements inform decisions, but none alone determines an operation or establishes that a kidney should be removed. The pages below explain indications, reference values and limitations.
