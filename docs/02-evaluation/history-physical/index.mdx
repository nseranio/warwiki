# History & Physical

The bedside evaluation consists of a structured history, validated assessment instruments and a systematic urogenital examination. It underlies every later test, image and operation. It defines the surgical question before any catheter, scope or scan, and an incomplete evaluation can send the patient down the wrong workup pathway.

This section covers the three elements of a reconstructive urology and urogynecology H&P: **validated assessment tools** that translate subjective symptoms into quantified severity, the **male urogenital examination** and the **female pelvic examination with POP-Q**.
