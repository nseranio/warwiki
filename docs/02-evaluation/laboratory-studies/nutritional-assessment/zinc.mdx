# Zinc

An essential trace element required for **DNA / protein synthesis, cell division, and wound healing** — directly relevant to the reconstructive patient because zinc is a cofactor for the matrix-metalloproteinases and collagen-synthesizing enzymes active in the proliferation phase.

## Key Cutoffs

- **Plasma zinc < 11 µmol/L (72 µg/dL) in men**
- **Plasma zinc < 10.4 µmol/L (68 µg/dL) in women**
- Levels are **suppressed by inflammation** (acute-phase response); interpret with CRP

## In Reconstruction

- Burn / chronic wound / pressure-ulcer evidence base is strongest; surgical-wound and BMG-graft-take evidence is weaker but mechanistically coherent.
- Multinutrient bundles (arginine + glutamine + vitamin C + zinc) significantly increase collagen synthesis in the early wound (Kjaer 2020 inguinal hernia RCT — see [Perioperative Nutrition](/docs/foundations/perioperative-care/postoperative-management/nutrition)).
- Post-bariatric and GLP-1 RA populations.
