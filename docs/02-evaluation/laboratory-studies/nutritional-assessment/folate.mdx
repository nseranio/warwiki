# Folate

A water-soluble B vitamin essential for nucleic-acid synthesis and erythropoiesis. Deficiency causes **macrocytic anemia** and, in early pregnancy, neural-tube defects.

## Key Cutoffs

- **RBC folate < 400 nmol/L** — deficient (preferred marker; reflects 3–4-month tissue status)
- **Serum folate < 6.8 nmol/L (3 ng/mL)** — also indicates deficiency (more reflective of recent intake)

## In Reconstruction

- High-yield in **women of reproductive age** scheduled for any reconstructive procedure where pregnancy is a downstream consideration (urogyn, GAS, lower-tract reconstruction).
- **Post-bariatric** surveillance (especially RYGB / BPD-DS).
- **GLP-1 RA users** with appetite suppression.
- Methotrexate / sulfasalazine / phenytoin users — drug-induced deficiency.
