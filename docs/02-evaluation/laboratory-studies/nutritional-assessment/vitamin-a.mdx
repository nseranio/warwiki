# Vitamin A

A fat-soluble vitamin essential for **epithelial differentiation, anti-inflammatory cytokine release, and immune function**. Topical or systemic vitamin A is the classic recovery agent for **steroid-impaired wound healing** — corticosteroids inhibit epithelialization and fibroblast proliferation; vitamin A reverses this effect.

## Key Cutoff

- **Serum retinol < 0.7 µmol/L (20 µg/dL)** — deficient
- Test is **relatively insensitive** to short-term change because hepatic stores buffer serum levels

## In Reconstruction

- Universal surveillance after **BPD-DS** and other malabsorptive bariatric procedures.
- Consider supplementation for the patient on chronic corticosteroids facing major reconstruction (autoimmune disease, transplant, post-cancer).
- Burn / pressure-ulcer / diabetic-ulcer evidence supports topical and oral vitamin A for chronic wound healing.
