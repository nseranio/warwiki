# Laboratory Studies

Laboratory testing in functional urology and urogynecology is anchored on **urine studies** — urinalysis, urine culture, urine cytology, prostatitis localization tests, 24-hour urine collections, and emerging expanded-quantitative-culture and next-generation-sequencing methods. Interpretation is fundamentally context-dependent: thresholds that define a UTI in a healthy outpatient woman are meaningless in a neobladder; a positive dipstick that triggers a hematuria workup in one patient is part of the baseline state in another. The pages below collect the validated thresholds, the AUA / IDSA / NCCN guideline-anchored recommendations, and the framework for interpreting these tests in the reconstructive-urology and urogynecology populations where standard cutoffs do not apply.
