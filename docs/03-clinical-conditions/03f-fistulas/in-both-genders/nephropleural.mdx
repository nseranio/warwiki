# Nephropleural Fistula

A **nephropleural fistula** — sometimes called a **reno-pleural** or **urino-pleural** fistula — is a communication between the renal collecting system and the pleural space, producing a **urinothorax**. The most common iatrogenic cause is a **supracostal PCNL puncture** with injury to the pleural reflection; the most common spontaneous cause is a longstanding ureteropelvic junction obstruction that decompresses across the diaphragm. Penetrating thoracoabdominal trauma is a third mechanism.

See also: [The Kidneys](/docs/foundations/anatomy-physiology/urinary-tract/renal-anatomy-physiology), [Fistulas landing page](/docs/clinical-conditions/03f-fistulas).
