# Resources

This section aggregates the practical tools and references used in the day-to-day practice of functional urology and reconstruction, including key textbooks, curated websites and online calculators, podcasts, a procedure-indexed library of surgical videos and atlases, patient-facing educational resources, and guidance on billing, coding, and reimbursement — intended as a living reference kept current alongside the rest of WARWIKI.
