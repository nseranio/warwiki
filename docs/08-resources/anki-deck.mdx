## How to import

1. **Download** the [CSV file](/anki/warwiki-anki-v1.csv).
2. Open Anki on desktop (the importer is more reliable than mobile clients).
3. **File → Import…** and select `warwiki-anki-v1.csv`.
4. The file's header instructs Anki to use tab as the field separator and column 3 as tags, and to place cards in a deck named **WARWIKI Anki Cards v1.0**. Confirm these settings in the import dialog if Anki prompts.
5. Anki creates the deck and applies the hierarchical tags (`WARWIKI::Foundations::Anatomy`, etc.) so you can filter by topic or build custom study sub-decks.

## How to study

- **All cards by default** — start with the full deck and let the scheduler triage by interval.
- **By topic** — in Anki, browse cards by tag and create a filtered deck for a single domain (e.g., `tag:WARWIKI::Surgical::Incontinence`).
- **Pre-rounds prep** — filter by `Surgical::*` for operative-day review; `Trauma::*` for ED call.
- **Board / fellowship review** — `Guidelines::*` plus the relevant clinical domain.

## What this is, and isn't

**Is:** a high-yield starter deck of clinical pearls, eponyms, key thresholds, and guideline anchors that map directly to the WARWIKI articles. Cards are written in surgeon-facing voice and emphasize decision points and operative-relevant numbers. Every card is anchored in content elsewhere on the site — use the site as the long-form context, the deck as the active-recall layer.

**Isn't:** an exhaustive board-review course or a substitute for primary literature. Many topics that warrant Anki coverage are not yet captured here (urodynamic interpretation pearls, pediatric urology transition, full BNC procedural detail, GAS revision algorithms, peri-prosthetic infection workup). Those will land in **v1.1** and later releases.

## Contributing

Spotted an error or want to add cards? Email **warwikihq@gmail.com** or open an issue on the [GitHub repository](https://github.com/nseranio/warwiki/issues). Card additions should:

- Map to existing site content (or trigger a new page if the topic isn't yet covered).
- Use the same tag taxonomy (`WARWIKI::<Section>::<Subtopic>`).
- Be tab-separated three-column TSV: `Front<TAB>Back<TAB>Tags`.
- Use specific, decision-relevant content over rote facts where possible.
