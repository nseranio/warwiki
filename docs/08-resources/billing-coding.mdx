## Billing Modifiers

Modifiers are appended to CPT codes to indicate special circumstances. This is a fixed reference set applicable across all procedure types.

| Modifier | Name | When to Use |
|---|---|---|
| **22** | Increased Procedural Services | Document complexity beyond typical; specify additional time required |
| **50** | Bilateral Procedure | Procedure performed on both sides |
| **51** | Multiple Procedures | Multiple procedures same session (typically applied automatically) |
| **52** | Reduced Services | Procedure partially reduced or a component eliminated |
| **53** | Discontinued Procedure | Procedure stopped after anesthesia due to extenuating circumstances |
| **58** | Staged / Related Procedure | Planned staged procedure or more extensive follow-up in post-op period |
| **59** | Distinct Procedural Service | Different session, site, organ, incision, lesion, or injury — document clearly |
| **62** | Co-Surgeon | Two primary surgeons performing distinct portions; each reports same CPT + 62 |
| **66** | Surgical Team | Highly complex surgery requiring multiple specialties simultaneously |
| **74** | Discontinued Outpatient / ASC Procedure | Procedure aborted after anesthesia started in outpatient or ASC setting |
| **76** | Repeat Procedure — Same Physician | Same CPT, same patient, same day (e.g., STSG at multiple sites) |
| **78** | Unplanned Return to OR | Related procedure during post-op global period |
| **79** | Unrelated Procedure in Post-op Period | Unrelated to primary procedure's post-op global |
| **80** | Assistant Surgeon | Primary surgeon bills CPT alone; assistant bills CPT + 80 |
| **82** | Assistant Surgeon (No Qualified Resident) | Must justify. Primary uses CPT only; assistant uses CPT + 82 |
| **XE** | Separate Encounter | Service distinct because it occurred during a separate encounter |
| **XS** | Separate Structure | Service distinct because performed on a separate organ or structure |
| **XP** | Separate Practitioner | Service distinct because performed by a different practitioner |
| **XU** | Unusual Non-Overlapping Service | Service does not overlap usual components of the main service |
