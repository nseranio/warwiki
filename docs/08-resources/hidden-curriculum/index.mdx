# The Hidden Curriculum

Clinical training teaches you to take care of patients. It doesn't teach you how the system in which you practice actually works — how money flows, how decisions are made, how operations are structured, how organizations scale. Framed for the reconstructive urologist, this section covers healthcare finance, payment models, hospital administration, billing and coding, practice management, and the pathway to physician leadership.
