# Gender-Affirming Surgery

This subsection covers surgical care for transgender and gender-diverse patients including feminizing procedures (vaginoplasty, vulvoplasty, orchiectomy), masculinizing procedures (phalloplasty, metoidioplasty, urethral lengthening), revision and salvage gender-affirming surgery, and non-binary and nullification procedures.
