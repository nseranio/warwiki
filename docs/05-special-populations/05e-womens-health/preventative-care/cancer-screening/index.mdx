# Cancer Screening

Age- and risk-stratified screening recommendations for the three cancers most often co-managed alongside female pelvic-floor surgery.

<ul className="toc-list">
  <li>
    <a href="/docs/special-populations/05e-womens-health/preventative-care/cancer-screening/cervical"><strong>Cervical Cancer Screening</strong></a>
    <span className="toc-desc">USPSTF / ACS / ASCCP screening intervals, primary HPV testing, and post-hysterectomy guidance.</span>
  </li>
  <li>
    <a href="/docs/special-populations/05e-womens-health/preventative-care/cancer-screening/breast"><strong>Breast Cancer Screening</strong></a>
    <span className="toc-desc">Mammography intervals, supplemental imaging in dense breasts, BRCA-elevated populations.</span>
  </li>
  <li>
    <a href="/docs/special-populations/05e-womens-health/preventative-care/cancer-screening/endometrial"><strong>Endometrial Cancer Screening</strong></a>
    <span className="toc-desc">No general-population screening; high-risk surveillance (Lynch, tamoxifen, obesity, postmenopausal bleeding workup).</span>
  </li>
</ul>
