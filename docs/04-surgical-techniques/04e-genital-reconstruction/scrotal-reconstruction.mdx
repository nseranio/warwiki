# Scrotal Reconstruction

Scrotal reconstruction after Fournier's gangrene, burn, or oncologic resection uses medial-thigh flaps, split-thickness skin grafting, or staged rotational flaps. Testicular coverage, sweat management, and scrotal contour drive technique selection.
