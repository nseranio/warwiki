# Tissue-Engineered Grafts / Bioscaffolds (Female)

**Tissue-engineered grafts and bioscaffolds** for female urethral reconstruction include **acellular matrices** (small intestinal submucosa, bladder acellular matrix) and **cell-seeded constructs**. Onlay use is clinically feasible in small series; tubularized constructs require cell seeding to avoid contracture and remain investigational.<sup>[[1]](#ref1)[[2]](#ref2)</sup>

For the male counterpart, see [Tissue-Engineered Oral Mucosa (TEOMG / MukoCell)](/docs/surgical-techniques/04a-urethral-reconstruction/tissue-engineered-oral-mucosa). For the broader scaffolding literature, see [Liquid / Minced Buccal Mucosal Graft](/docs/surgical-techniques/04a-urethral-reconstruction/liquid-minced-buccal).

---

## Concept

| Construct | Cell-seeded? | Status |
|---|---|---|
| Small intestinal submucosa (SIS) | No | Onlay clinical use |
| Bladder acellular matrix | No | Onlay clinical use |
| Tubularized SIS / acellular | No | High contracture rate; not viable |
| Cell-seeded scaffolds (Atala-type) | Yes | Investigational |
