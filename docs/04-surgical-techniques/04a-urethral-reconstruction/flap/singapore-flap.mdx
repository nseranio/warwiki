# Singapore Flap Urethroplasty

The Singapore flap, originally described for vaginal reconstruction,<sup>[[1]](#ref1)</sup> uses a pedicled fasciocutaneous island from the medial thigh based on the posterior labial or perineal perforators.<sup>[[1]](#ref1)[[2]](#ref2)</sup> When applied to urethral reconstruction, it provides a robust, well-vascularized segment of hairless skin suitable for complex perineal urethral defects. It is particularly valuable in cases requiring simultaneous urethral and perineal soft tissue reconstruction.<sup>[[2]](#ref2)</sup>
