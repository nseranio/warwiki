# Surgical Techniques

This section is organized by technical domain and addresses how problems are fixed, serving as the operative reference core of WARWIKI — spanning urethral and bladder reconstruction, urinary diversion, upper tract surgery, tissue transfer (grafts and flaps), incontinence procedures, prolapse repair, prosthetic implantation, and endoscopic interventions, with enough detail to support pre-operative planning, intraoperative decision-making, and trainee education.
