# Right Colon Pouch

A detubularized right colonic segment used as a continent catheterizable urinary reservoir, representing an early configuration in the development of the Indiana pouch. Uses the ileocecal region for low-pressure reservoir construction; suitable when the ileum is limited, previously irradiated, or otherwise compromised.
