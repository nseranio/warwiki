# Double T-Pouch

The double T-pouch is a continent catheterizable urinary reservoir constructed from an ileal segment configured in a double T-shape to optimize low-pressure capacity. Accessed via intermittent catheterization through an abdominal continent stoma; intended for patients ineligible for orthotopic reconstruction who prefer catheterization over an external appliance.
