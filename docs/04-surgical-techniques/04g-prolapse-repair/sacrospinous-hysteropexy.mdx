# Sacrospinous Hysteropexy

Uterine suspension to the sacrospinous ligament preserving the uterus, using permanent sutures or mesh tape; a uterus-conserving alternative to hysterectomy for uterine prolapse. Increasingly favored by patients desiring uterine preservation with short-term outcomes comparable to vaginal hysterectomy with SSLF.
