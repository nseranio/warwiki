# Manchester-Fothergill Procedure

Combined anterior colporrhaphy with cervical amputation and bilateral cardinal ligament plication onto the cervical stump to restore apical support while preserving the uterus. A uterus-conserving apical repair for uterine prolapse originally described in the early 20th century; remains appropriate for selected patients who decline hysterectomy.
