# Vaginal Hysterectomy for Prolapse

Removal of the uterus via the vaginal route as the index procedure for symptomatic uterine prolapse, combined with an apical support repair (McCall's culdoplasty, SSLF, or USLS). Standard surgical treatment when uterine preservation is not desired; shorter recovery than abdominal hysterectomy.
