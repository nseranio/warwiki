# Kelly Plication

Historical anterior colporrhaphy technique combining bladder base plication with urethrovesical angle correction for concurrent stress urinary incontinence and anterior prolapse. Largely supplanted by suburethral slings for SUI and by more durable anterior repair techniques; retained as a foundational reference.
