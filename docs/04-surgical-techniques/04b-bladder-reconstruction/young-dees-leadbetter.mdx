# Young-Dees-Leadbetter Procedure

Bladder neck tubularization using trigonal muscle strips to create a competent outlet. Classic technique for pediatric neurogenic bladder incompetence; applied in adults for severe post-prostatectomy or radiation BNC when combined continence reconstruction is required.
