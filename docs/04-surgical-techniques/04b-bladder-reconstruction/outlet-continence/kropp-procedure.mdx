# Kropp Procedure

Creation of a continent catheterizable channel using a posterior bladder wall tube to replace or bypass an obliterated bladder neck outlet. Primarily a pediatric neurogenic technique (myelomeningocele, bladder exstrophy) adapted for adults with obliterated outlet and neurogenic dysfunction.
