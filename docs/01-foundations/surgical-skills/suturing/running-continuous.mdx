# Running Continuous

The **running continuous** stitch is a single length of suture passing repeatedly through tissue, secured at both ends. Fast, uniform tension distribution, fewer knots — the default for fascia, bladder wall, and any closure where uniform tension is desirable.

## Technique

- Start with a simple interrupted throw and tie; leave the tail long or cut one tail only
- Pass the suture through tissue in a regular pattern at uniform bite depth
- Maintain **uniform tension** with the non-dominant hand on the trailing suture
- Finish with a traditional tail-on-tail knot or an [Aberdeen knot](/docs/foundations/surgical-skills/knot-tying/aberdeen-knot)

## Key Uses in Reconstructive Urology

- Fascial closure
- Bladder closure (single- or two-layer running)
- Bowel single-layer running closure (per contemporary evidence in [Bowel Anastomosis](/docs/foundations/surgical-principles/bowel-anastomosis))
- Urethroplasty onlay / tubularized closure (particularly robotic)
- Vesicourethral anastomosis — see [Van Velthoven running VUA](/docs/foundations/surgical-skills/special-techniques/van-velthoven-vua)

## Key Considerations

- **Tension:** must be uniform — too tight cuts tissue, too loose leaves gaps
- **Bite depth:** consistent throughout — irregular depth creates stress concentration
- A **break anywhere** unravels the entire closure — beware in contaminated or tension fields
- **Tag** with a small interrupted or Lembert stitch at the corners if uncertain
