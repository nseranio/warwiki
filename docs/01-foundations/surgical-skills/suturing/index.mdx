# Suturing Patterns

A catalog of the stitch patterns a reconstructive urologist uses. **General-purpose patterns** (simple interrupted, running, mattress variants, figure-of-eight, purse-string, subcuticular) cover skin, fascia, urinary tract, and general wound closure. **Bowel-specific patterns** (Connell, Lembert, Cushing, Halsted) are inverting or imbricating stitches developed for hollow-viscus anastomosis — ubiquitous on urinary-diversion trays.

## Bowel-Specific Patterns

<ul className="section-stack">
  <li>
    <a href="/docs/foundations/surgical-skills/suturing/connell-stitch" className="section-stack-title section-stack-link">Connell Stitch</a>
    <span className="section-stack-desc">Continuous full-thickness inverting stitch — the classic inner layer of hand-sewn bowel anastomosis.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/suturing/lembert-stitch" className="section-stack-title section-stack-link">Lembert Stitch</a>
    <span className="section-stack-desc">Seromuscular inverting stitch — classic outer layer of two-layer bowel closure; named for Antoine Lembert (1826).</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/suturing/cushing-stitch" className="section-stack-title section-stack-link">Cushing Stitch</a>
    <span className="section-stack-desc">Continuous seromuscular inverting pattern — alternative outer layer for bowel anastomosis.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/suturing/halsted-stitch" className="section-stack-title section-stack-link">Halsted Stitch</a>
    <span className="section-stack-desc">Interrupted seromuscular inverting stitch — named for William Halsted; basis of meticulous bowel and vascular anastomosis.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/suturing/parker-kerr-stitch" className="section-stack-title section-stack-link">Parker-Kerr Stitch</a>
    <span className="section-stack-desc">Two-layer inverting stump closure — running over-the-clamp baseball stitch + Lembert reinforcement. Workhorse technique for ileal conduit and neobladder end closure.</span>
  </li>
</ul>

## Suturing Skills — External Video Resources
