# Running Locking (Baseball Stitch)

The **running locking** stitch — often called the **baseball stitch** — is a running continuous pattern where each pass is **locked** by bringing the needle through the previous loop before advancing. The lock prevents back-tension from pulling the stitch loose and provides **hemostasis along the wound edge**.

## Technique

- Pass the needle through both tissue edges
- Before pulling the suture taut, bring the needle through the loop created by the previous throw
- Tighten — the loop locks around the previous pass
- Advance to the next stitch position

## Key Uses

- **Urethral anastomosis** — hemostatic closure at the urethral mucosa
- **Bladder closure** — particularly at mucosal edge
- **Skin closure** (rarely — mostly trauma) where hemostasis is essential
- **Mucosal closures** in general
- Historical: trauma laparotomy vascular bed closure

## Why "Baseball"

The suture pattern across the closure resembles the stitching on a baseball seam — each throw perpendicular to the wound, with a locking loop visible on the surface.

## Considerations

- **More hemostatic** than simple running — chokes off small vessels at the wound edge
- **Less cosmetic** — the surface pattern is more visible
- **Slower** than simple running but faster than interrupted
