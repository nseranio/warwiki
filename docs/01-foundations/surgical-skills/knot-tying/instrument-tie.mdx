# Instrument Tie

The **instrument tie** uses a needle holder (or forceps) to loop the suture around itself — the default technique for **microsurgery, fine suture, short suture tails, and deep restricted fields** where hand ties are impractical.

## Construction

- Hold the long tail with the non-dominant hand
- Wrap the suture around the needle holder (one wrap for a single throw, two for a surgeon's knot first throw)
- Grasp the short tail with the needle holder and pull through the loop
- **Alternate direction each throw** to build a square knot

## Key Uses in Reconstructive Urology

- Microsurgical vasovasostomy and vasoepididymostomy (always instrument tie)
- Urethral anastomosis (4-0 and finer suture)
- Deep pelvic reconstruction where hand depth is inadequate
- Any closure with suture tails too short for comfortable hand tying
- Fine skin closure where suture conservation matters

## Technique Pearls

- Needle holder position matters — the jaw axis determines the knot direction
- **Keep tension on the long tail** throughout the wrap to prevent throw migration
- For microsurgery: **never grasp the suture itself with the needle holder** — only loop the suture over the jaws
