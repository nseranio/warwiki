# Knot Tying

Every operation is held together by knots. A reconstructive surgeon needs a **small set of reliable knots that can be tied in any field, at any depth, with any suture material**. Mastery of two-handed and one-handed ties, the instrument tie, and the surgeon's knot covers the vast majority of open reconstruction; the Aberdeen finishes a running closure; the laparoscopic/knot-pusher technique handles deep endoscopic fields where the fingers cannot reach.

## Techniques

<ul className="section-stack">
  <li>
    <a href="/docs/foundations/surgical-skills/knot-tying/two-handed-square-knot" className="section-stack-title section-stack-link">Two-Handed Square Knot</a>
    <span className="section-stack-desc">Foundation knot — bilateral hand participation, maximum control, lowest failure rate.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/knot-tying/one-handed-tie" className="section-stack-title section-stack-link">One-Handed Tie</a>
    <span className="section-stack-desc">Efficient single-hand throws used when the opposite hand is occupied with tissue or suture tension.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/knot-tying/instrument-tie" className="section-stack-title section-stack-link">Instrument Tie</a>
    <span className="section-stack-desc">Needle-holder-based knot — the default for microsurgery, fine suture, short tails, and deep restricted fields.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/knot-tying/surgeons-knot" className="section-stack-title section-stack-link">Surgeon's Knot</a>
    <span className="section-stack-desc">Double-throw first knot that locks under tension — used for slippery suture material or tissue under tension.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/knot-tying/slip-knot" className="section-stack-title section-stack-link">Slip Knot</a>
    <span className="section-stack-desc">Tensioning knot that can be progressively tightened before locking — useful for apical suspension and deep-pelvic work.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/knot-tying/aberdeen-knot" className="section-stack-title section-stack-link">Aberdeen Knot</a>
    <span className="section-stack-desc">Terminal knot for running continuous closure — secures the end without a tail-on-tail tie.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/knot-tying/laparoscopic-knot" className="section-stack-title section-stack-link">Laparoscopic / Knot Pusher</a>
    <span className="section-stack-desc">Extracorporeal knot construction delivered through a cannula with a knot pusher — pre-robotic MIS technique still relevant for select open-suture laparoscopic applications.</span>
  </li>
</ul>
