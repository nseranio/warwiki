# One-Handed Tie

The **one-handed tie** allows a surgeon to create throws with a single hand while the other hand maintains tissue tension or holds a suture tail. Fundamental for high-throughput closure and any situation where both hands cannot be dedicated to knot construction.

## Variants

- **One-handed square knot** — alternating throws with the same hand, reversing direction each time
- **One-handed surgeon's knot** — double-wrapped first throw, one-handed

## Key Uses

- Running fascial closure with one hand maintaining suture tension
- Deep-field closure where the non-dominant hand holds a retractor
- High-volume closure (faster throw-to-throw than two-handed)

## Technique Pearls

- Practice on a bench with rope before OR — the hand position is counterintuitive
- Learn both **left-hand** and **right-hand** versions
- **Maintain tension on the active throw** — one-handed throws are more prone to loose first-throws
