# Aberdeen Knot

The **Aberdeen knot** is a **terminal knot for ending a running continuous closure**. It secures the suture end without requiring the traditional tail-on-tail tie — particularly useful when one tail is too short to tie comfortably.

## Construction

At the end of a running closure:
- A loop of suture is pulled from the last pass
- The loop is passed through itself **three to four times** in sequence (hence variations: triple Aberdeen, quadruple Aberdeen)
- Each pass tightens the previous
- The final pass locks the series

## Key Uses

- **End of a running fascial closure** when the tail is short
- **Running subcuticular** skin closure termination
- Running closures where a bulky end-knot would cause tissue irritation or palpability

## Advantages

- **Buried** — the knot is incorporated into the final loop, not separate
- **Flat** — minimal tissue profile
- **Consistent** — reproducible tension

## Technique Pearls

- **Count your passes** — three is the minimum; four is more secure but adds suture volume
- The pattern is counterintuitive — practice on bench-top models before in-vivo use
- **Suture tension** during construction determines final knot security; each pass should be laid down taut
