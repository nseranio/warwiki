# Named GU Operative Techniques

Named, eponymous techniques that define functional-urology, reconstructive-urology, and urogynecology operative practice — the maneuvers a GURS or URPS surgeon recognizes by name and uses to finish cases that nobody else in the OR can. Generic suturing patterns and knot tying are covered in any surgery textbook; this section sticks to the **signature techniques** of the reconstructive operative repertoire.

For generic bowel anastomotic stitches (Connell, Cushing, Lembert, Halsted), see the *Bowel Anastomotic Stitches* subsection of [Bowel Anastomosis](/docs/foundations/surgical-principles/bowel-anastomosis#bowel-anastomotic-stitches).

## Techniques

| Technique | Signature use | Context |
|---|---|---|
| [**Heaney stitch**](/docs/foundations/surgical-skills/heaney-stitch) | Vaginal-cuff closure with pedicle incorporation | Vaginal hysterectomy, colpotomy closure |
| [**Quilting stitch**](/docs/foundations/surgical-skills/quilting-stitch) | Tissue-to-tissue dead-space obliteration | Flap fixation, seroma prevention, BMG quilting |
| [**Ski needle**](/docs/foundations/surgical-skills/ski-needle) | Deep, at-depth anastomoses with restricted needle excursion | Robotic and open deep-pelvic work |
| [**Van Velthoven VUA**](/docs/foundations/surgical-skills/van-velthoven-vua) | Two-suture continuous vesicourethral anastomosis | Robotic prostatectomy, cystectomy reconstruction |
| [**Parker-Kerr stitch**](/docs/foundations/surgical-skills/parker-kerr-stitch) | Over-the-clamp baseball + Lembert two-layer stump closure | Bowel-segment closure during urinary diversion |
| [**SEXI — Stance Exchange In situ**](/docs/foundations/surgical-skills/sexi-stance-exchange) | Five needle-handling maneuvers to change stance without remounting | Any running / interrupted anastomosis; deep pelvic and perineal work |
