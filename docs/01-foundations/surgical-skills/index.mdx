# Surgical Skills

Named stitches and signature techniques that define GURS and URPS operative practice. Generic suturing and knot-tying are covered in any surgery textbook; this section focuses on the **techniques a functional-urology, reconstructive-urology, or urogynecology surgeon recognizes by name** and uses to finish cases that nobody else in the OR can.

## Techniques

| Technique | Signature use | Context |
|---|---|---|
| [**Connell stitch**](/docs/foundations/surgical-skills/connell-stitch) | Continuous inverting full-thickness bowel anastomosis | Urinary diversion, bowel reconstruction |
| [**Cushing stitch**](/docs/foundations/surgical-skills/cushing-stitch) | Continuous inverting seromuscular | Bowel anastomosis outer layer |
| [**Lembert stitch**](/docs/foundations/surgical-skills/lembert-stitch) | Interrupted seromuscular inverting | Bowel anastomosis outer layer |
| [**Halsted stitch**](/docs/foundations/surgical-skills/halsted-stitch) | Interrupted Lembert variant (double-bite) | Bowel anastomosis, high-tension reinforcement |
| [**Parker-Kerr stitch**](/docs/foundations/surgical-skills/parker-kerr-stitch) | Over-the-clamp baseball + Lembert two-layer stump closure | Bowel-segment closure during urinary diversion |
| [**Heaney stitch**](/docs/foundations/surgical-skills/heaney-stitch) | Vaginal-cuff closure with pedicle incorporation | Vaginal hysterectomy, colpotomy closure |
| [**Quilting stitch**](/docs/foundations/surgical-skills/quilting-stitch) | Tissue-to-tissue dead-space obliteration | Flap fixation, seroma prevention |
| [**Ski needle**](/docs/foundations/surgical-skills/ski-needle) | Deep, at-depth anastomoses with restricted needle excursion | Robotic and open deep-pelvic work |
| [**Van Velthoven VUA**](/docs/foundations/surgical-skills/van-velthoven-vua) | Two-suture continuous vesicourethral anastomosis | Robotic prostatectomy, cystectomy reconstruction |
