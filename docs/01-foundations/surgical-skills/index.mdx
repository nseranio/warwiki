# Surgical Skills

The manual repertoire of reconstructive surgery — the knots, stitches, ligatures, and named techniques that translate operative judgment into tissue. This section catalogs the specific skills a functional-urology and GU-reconstruction surgeon uses every day, organized around four practical groupings.

## Sections

<ul className="section-stack">
  <li>
    <a href="/docs/foundations/surgical-skills/knot-tying" className="section-stack-title section-stack-link">Knot Tying</a>
    <span className="section-stack-desc">Two-handed and one-handed ties, instrument tie, surgeon's knot, slip knot, Aberdeen, laparoscopic / knot pusher.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/suturing" className="section-stack-title section-stack-link">Suturing Patterns</a>
    <span className="section-stack-desc">Simple and running closures, vertical and horizontal mattress, figure-of-eight, purse-string, subcuticular — plus the bowel-specific stitches (Connell, Lembert, Cushing, Halsted).</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/ligatures" className="section-stack-title section-stack-link">Ligatures</a>
    <span className="section-stack-desc">Free tie, suture ligature, transfixion / stick tie, clip ligation, and energy sealing — the methods of vessel control.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/special-techniques" className="section-stack-title section-stack-link">Special Techniques</a>
    <span className="section-stack-desc">Named and signature techniques — Heaney stitch, quilting, ski needle, Van Velthoven running VUA, barbed-suture closure.</span>
  </li>
</ul>
