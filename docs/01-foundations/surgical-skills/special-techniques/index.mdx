# Special Techniques

Named and signature techniques in reconstructive urology — each with a specific indication, a distinctive geometry, and (usually) a surgeon's name attached.

## Techniques

<ul className="section-stack">
  <li>
    <a href="/docs/foundations/surgical-skills/special-techniques/heaney-stitch" className="section-stack-title section-stack-link">Heaney Stitch</a>
    <span className="section-stack-desc">Classic pedicle suture-ligature — double-throw lock around a clamp; the foundational hemostatic technique for pedicled pelvic pedicles.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/special-techniques/quilting-stitch" className="section-stack-title section-stack-link">Quilting Stitch</a>
    <span className="section-stack-desc">Tacks flap or skin-flap tissue to underlying bed to close dead space and reduce seroma — borrowed from plastic surgery.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/special-techniques/ski-needle" className="section-stack-title section-stack-link">Ski Needle Technique</a>
    <span className="section-stack-desc">Laparoscopic suturing with a shaped "ski-curve" needle that passes through the cannula and negotiates deep pelvic angles.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/special-techniques/van-velthoven-vua" className="section-stack-title section-stack-link">Van Velthoven Running VUA</a>
    <span className="section-stack-desc">Continuous running vesicourethral anastomosis using a double-armed suture — the standard robotic prostatectomy VUA technique.</span>
  </li>
  <li>
    <a href="/docs/foundations/surgical-skills/special-techniques/barbed-suture-closure" className="section-stack-title section-stack-link">Barbed Suture Closure</a>
    <span className="section-stack-desc">Self-retaining knotless closure — increasingly used for running fascial, urethral, and visceral closures in robotic and open reconstruction.</span>
  </li>
</ul>
