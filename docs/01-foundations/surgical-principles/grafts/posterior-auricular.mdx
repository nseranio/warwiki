# Posterior Auricular Skin Graft

A full-thickness skin graft harvested from the retroauricular (postauricular) sulcus — the skin between the pinna and mastoid. Uniquely thin, non-hair-bearing, supple skin with favorable cosmetic properties and a hidden donor scar.

See the overview article for the reference summary: [Grafts in GU Reconstruction](/docs/foundations/surgical-principles/grafts-gu-reconstruction).
