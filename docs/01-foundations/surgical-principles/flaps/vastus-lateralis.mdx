# Vastus Lateralis Flap

A pedicled or free myocutaneous / muscle-only flap harvested from the vastus lateralis, based on the **descending branch of the lateral circumflex femoral artery** (same pedicle as the ALT flap). Provides large muscle bulk for deep pelvic dead-space obliteration.

See the overview article for the reference summary: [Flaps in GU Reconstruction](/docs/foundations/surgical-principles/flaps-gu-reconstruction).
