# Pedicled Penile / Preputial Skin Flap

Local pedicled skin flap harvested from the penile shaft or prepuce, based on the dartos fascia vascular plexus supplied by branches of the superficial external pudendal artery.

See the overview article for the reference summary: [Flaps in GU Reconstruction](/docs/foundations/surgical-principles/flaps-gu-reconstruction).
