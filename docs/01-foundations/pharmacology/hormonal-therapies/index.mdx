# Hormonal Therapies

Hormonal pharmacotherapy for GSM, recurrent-UTI prevention, perioperative care, and gender-affirming treatment. The linked hubs distinguish approved indications and product-specific dosing from off-label use, surrogate tissue findings, and clinical outcomes. IMPROVE did not show better prolapse-repair success with routine estrogen priming. FDA menopausal-hormone labeling changes require checking each product.

For testosterone replacement in male hypogonadism see [Sexual Medicine & Andrology](/docs/foundations/pharmacology/sexual-medicine-andrology/testosterone-replacement). For [GSM](/docs/special-populations/05e-womens-health/gsm) and [Gender-Affirming Surgery](/docs/special-populations/05c-gender-affirming) clinical articles see the linked pages.
