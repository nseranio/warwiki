# Gear

Equipment worn or used by the surgeon: optical aids, radiation protection and practical ergonomic supports. Selection should reflect the procedure, individual fit and the operating environment.

## Sections

<ul className="section-stack">
  <li>
    <a href="/docs/foundations/tools/gear/optical-aids" className="section-stack-title section-stack-link">Optical Aids</a>
    <span className="section-stack-desc">Surgical loupes (Galilean vs prismatic, TTL vs flip-up, magnification and working distance), LED headlights with model-specific positioning evidence, and surgical microscope indications.</span>
  </li>
  <li>
    <a href="/docs/foundations/tools/gear/radiation-protection" className="section-stack-title section-stack-link">Radiation Protection</a>
    <span className="section-stack-desc">Lead aprons (composite / lead-free options, two-piece vs one-piece), thyroid shield, protective eyewear with lateral shielding, collar / waist / ring dosimetry, ALARA principles.</span>
  </li>
  <li>
    <a href="/docs/foundations/tools/gear/ergonomics" className="section-stack-title section-stack-link">Ergonomics &amp; Longevity</a>
    <span className="section-stack-desc">OR shoes, compression stockings, anti-fatigue mats, saddle stools and seated work, individual fit and posture considerations.</span>
  </li>
</ul>
