# Ski Needle / J-Hook Needle

The **ski / J-hook needle** has a comparatively straight shaft with a **short distal curve**, unlike a deeply curved full arc. In one published posterior substitution-urethroplasty technique, the surgeon bends one needle of a 5-0 double-armed PDS suture slightly to make this shape for deep **proximal apical graft sutures**. This is one group's technique, not a manufactured device with comparative outcome data.<sup>[[1]](#ref1)</sup>

## Where it is useful

- **Dorsal-onlay BMG repair for posterior urethral stenosis**, including selected [BNC](/docs/surgical-techniques/04ab-bladder-neck-reconstruction/bnc) / [VUAS](/docs/surgical-techniques/04ab-bladder-neck-reconstruction/vuas) cases: grasp the needle **parallel to the driver**, pass it outside-in at the junction of the healthy proximal urethra and graft bed, and use a second driver to retrieve the tip. See the [Dorsal Onlay BMG atlas](/docs/surgical-techniques/04ab-bladder-neck-reconstruction/bnc-vuas/dorsal-bmg-bnc).<sup>[[1]](#ref1)</sup>
- For a very deep proximal defect the same authors describe the **RD-180** suturing device (LSI Solutions) as an alternative for apical placement. The paper does not compare the two.<sup>[[1]](#ref1)</sup>
