# Singley Tissue Forceps

**Long, angled tips with fine serrations** — designed for **atraumatic handling of bowel and ureter**. Frequently seen on urinary-diversion trays.

## Design

- **Long shaft** reaches deep abdominal structures
- **Angled tips** allow approach to tubular structures from the side
- **Fine serrations, no teeth** — atraumatic grip on hollow viscera

## Key Uses

- Ileal conduit construction — bowel segment handling
- Orthotopic neobladder — bowel mobilization
- Continent cutaneous reservoir — pouch manipulation
- Mitrofanoff construction — appendiceal or ileal channel handling
- Ureteral handling during reimplantation and anastomosis
