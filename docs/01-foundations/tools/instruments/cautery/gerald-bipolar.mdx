# Gerald Bipolar Forceps

**Fine-tipped bipolar forceps** for precision hemostasis in delicate fields.

## Design

- **Two tips serve as active and return electrodes** — current flows only between them, no grounding pad required
- **Fine tapered profile**
- **Minimal collateral thermal spread** — current confined to the tissue grasped between the tips

## Key Uses in Reconstructive Urology

- Vasal branch and testicular artery branch coagulation (microsurgery)
- Dartos vessel hemostasis (hypospadias, urethroplasty, phalloplasty)
- Periurethral venous control
- Penile neurovascular bundle adjacent dissection
- Any reconstructive field where monopolar spread would damage critical structures
