# Ryder Needle Holder

The parent of the [Turner-Warwick Ryder](/docs/foundations/tools/instruments/needle-holders/turner-warwick-ryder) variant. **Fine, delicate jaws** designed for **small-diameter needles** (4-0 and finer), with a shorter shank than the Turner-Warwick modification. Workhorse for microsurgical and reconstructive anastomotic work where precise needle control matters more than gripping force.

## Key Uses

- Vasovasostomy and vasoepididymostomy
- Urethral anastomotic suture placement
- Fine vascular anastomosis
- Any reconstructive field using 4-0 to 6-0 suture

See also: [Turner-Warwick Ryder](/docs/foundations/tools/instruments/needle-holders/turner-warwick-ryder), [Castroviejo](/docs/foundations/tools/instruments/needle-holders/castroviejo).
