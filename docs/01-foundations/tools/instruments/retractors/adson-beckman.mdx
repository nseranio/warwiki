# Adson-Beckman Retractor

**Self-retaining wound retractor** with spring-opposed blades and a ratcheted frame.

## Design

- **Two opposing blades** on a ratcheted ring
- **Spring-opposed** — maintains retraction without assistant force
- **Compact profile** — suitable for shallow wounds

## Key Uses

- Scrotal exposures (IPP placement, orchiectomy, hydrocelectomy)
- Inguinal incisions (hernia, varicocelectomy)
- Superficial perineal wounds where full self-retaining systems are overkill
