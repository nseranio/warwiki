# Tools

The material and technological toolkit of functional and reconstructive urology — **instruments** on the tray, **technology** platforms in the operating room, **biomaterials** implanted into patients, **intraoperative adjuncts** applied at the table, and the **gear** the surgeon wears. Each subsection is a searchable reference organized around how these tools are actually used in practice. For drugs, see [Pharmacology](/docs/foundations/pharmacology).
