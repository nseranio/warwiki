# Tools

The material and technological toolkit of functional and reconstructive urology has four parts: instruments on the tray, technology platforms in the operating room, biomaterials implanted into patients, and the gear the surgeon wears. Each subsection is a searchable reference organized by how these tools are used in practice. For intraoperative agents (ICG, FloSeal, fibrin sealants, TXA, and the rest), see [Intraoperative adjuncts](/docs/foundations/pharmacology/intraoperative-adjuncts) under Pharmacology. For other drugs, see [Pharmacology](/docs/foundations/pharmacology).
