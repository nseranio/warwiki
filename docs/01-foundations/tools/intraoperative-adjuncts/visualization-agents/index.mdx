# Visualization Agents — Dyes and Fluorophores

Agents administered to **see what cannot be seen with ambient light** — perfusion, lymphatic drainage, ureteral course, fistula tracts, urethral anastomotic integrity. Divided by detection modality into **visible-light dyes** (methylene blue, indigo carmine, sodium fluorescein — seen directly by the naked eye) and **near-infrared (NIR) fluorophores** (ICG, pudexacianinium — invisible to the naked eye, visualized through dedicated NIR imaging on laparoscopic/robotic platforms).

---

## Agent Library

| Agent | Class | Route | Primary GU applications |
|---|---|---|---|
| **[Indocyanine green (ICG)](/docs/foundations/tools/intraoperative-adjuncts/visualization-agents/icg)** | NIR fluorophore | IV, direct instillation, intraureteral stent coating | Perfusion, ureter mapping, lymphatic mapping, bladder-flap viability, IPP BNC localization |
| **[Methylene blue](/docs/foundations/tools/intraoperative-adjuncts/visualization-agents/methylene-blue)** | Visible dye | Intravesical, intraureteral, IV, injection | VVF/UVF localization, ureteral-orifice identification, urethral anastomotic leak test, lymphatic mapping |
| **[Indigo carmine](/docs/foundations/tools/intraoperative-adjuncts/visualization-agents/indigo-carmine)** | Visible dye | IV | **Historical** ureteral identification; intermittent supply shortages since 2014 |
| **[Sodium fluorescein](/docs/foundations/tools/intraoperative-adjuncts/visualization-agents/sodium-fluorescein)** | Visible / UV dye | IV, intravesical | Perfusion, urinary leak detection, ophthalmologic cross-use |
| **[Pudexacianinium (ASP-5354)](/docs/foundations/tools/intraoperative-adjuncts/visualization-agents/pudexacianinium)** | NIR fluorophore | IV | Dedicated NIR ureteral visualization — developed to replace indigo carmine for ureter identification in MIS |

## Detection Modality

### Visible-light dyes

- **Methylene blue** (deep blue) and **indigo carmine** (blue-violet) — seen directly; concentration determines intensity
- **Sodium fluorescein** — yellow-green under ambient light; intensifies under UV or cobalt-blue filter

### Near-infrared (NIR) fluorescence

- **ICG** peak excitation ~800 nm, emission ~830 nm — requires a dedicated NIR-enabled imaging system:
  - **Firefly** (Intuitive Surgical da Vinci platforms) — the most widely deployed
  - **SPY / Luna-IR** (Stryker) — open and laparoscopic use
  - **PINPOINT** (Novadaq/Stryker) — laparoscopic
  - **IMAGE1 S Rubina** (Karl Storz) — laparoscopic
- **Pudexacianinium** uses the same NIR wavelength window as ICG; visualized on the same imaging hardware

### Practical implication

A surgeon without access to an NIR-enabled platform is limited to visible-light dyes for intraoperative visualization. In robotic centers with Firefly, ICG has become the dominant agent for perfusion, lymphatic, and — increasingly — ureteral mapping.
