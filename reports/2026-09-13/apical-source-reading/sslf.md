**Zhang 2022, DOI 10.1007/s00192-021-04823-w, PMC8739324:** complete article-only text **40,874 characters**, contiguous [0,21000) and [21000,40874); all three table texts, 33 reference entries and all seven actual original-resolution graphics read. No separate supplemental link identified in the complete PMC article. This is a mixed-design review (5 RCTs, 8 retrospective and 2 prospective studies; 4,120 cases), search through October 2020, with open/laparoscopic, uterine/vault and some graft-containing or concomitant-operation comparisons. It is not a homogeneous modern native-tissue vault SSLF comparison. Important source inconsistencies:

- Tables 2 and 3 duplicate sensitivity-analysis numbers despite different captions.
- Figure 5 is captioned as vault recurrence but actually displays pooled overall recurrence (SSLF 263/2320 versus SCP 124/1570), consistent with the main pooled result, not the smaller compartment-only analysis described in prose.
- ASC hemorrhage CI is 0.25–0.82 in actual Figure 2 but 0.25–0.85 in prose; ASC recurrence CI is 1.04–3.76 in actual Figure 5 but 1.04–3.46 in prose.
- Main text overgeneralizes some open-route comparisons; sensitivity analyses lose significance for several complication endpoints. The site does not repeat these pooled risk numbers.
- Actual Figure 7 is a funnel plot, not evidence that publication bias is absent. Reading the review's references is not reading each underlying trial.

**Vodegel 2022, DOI 10.1111/1471-0528.17145, PMC9545288:** complete article-only text **36,029 characters**, contiguous [0,19000) and [19000,36029); all four table texts/footnotes, 26 reference entries and actual Figure 1 read. All 21 patients were selected for severe/persistent pain and suture removal in a referral setting. At approximately 6–8 weeks, 12/21 had complete and 8/21 partial relief; 2/21 had new symptomatic prolapse, while 4/21 total had symptomatic prolapse because two were already affected. Six had anatomical stage ≥2. Five ICMJE disclosure PDFs were linked; every actual PMC URL returned a small non-PDF challenge document, so **none of those disclosure forms is claimed read**. There is no long-term recurrence result in this series, nor proof of effectiveness of unmeasured concurrent conservative treatment. Table 4 itself displays “42.9 (9/12)” for simultaneous procedures, an internal denominator mismatch; not reproduced.

**Athanasiou 2026, DOI 10.3390/jcm15114209, PMC13257654:** complete article-only text **57,158 characters**, contiguous [0,19000), [19000,38000), [38000,57158); all two study-table texts, abbreviation table, 46 reference entries, disclosures and data statements. Its Table 1 labels bilateral-versus-unilateral values while the corresponding Jones narrative reverses the group attribution; Table 2 requires distinguishing change in point C from postoperative absolute C. Its description of a loop-suture study as pending is outdated relative to the published 2025 retrospective abstract. Its population prevalence and generalized device superiority are not adopted.
